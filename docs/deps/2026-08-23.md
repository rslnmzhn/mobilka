## Risky patterns

- Deprecated packages: none. All publishers are first-party (dart.dev, flutter.dev,
  fluttercommunity.dev verified publishers); share_plus is a Flutter Favorite.
- Production-deps-on-dev-tools: none.
- Oversized trees: moderate. share_plus adds cross_file, ffi, file, mime, web, win32
  (^6.0.1), plus the four url_launcher packages. win32 is large but standard for any
  Windows plugin; acceptable.
- Functional caveats worth knowing (not blockers):
  - share_plus cannot share **files on Linux** (text-only via mailto fallback). The app
    targets Linux; artifact file-sharing on Linux must degrade gracefully.
  - Share.share/shareUri/shareXFiles statics are deprecated in favor of
    `SharePlus.instance.share(ShareParams(...))`; repo code already documents this
    migration intent (lib/features/artifacts/data/artifact_share_bridge.dart).
